Projects & achievements

Autonomous Mini-SOC / SOAR — Master's final-year project
2026 – Present
Self-hosted on Proxmox · no public exposure (Tailscale-only access)
  • SIEM: deployed Wazuh (manager and indexer) to centralize pfSense firewall logs, Suricata IDS (EVE JSON), CrowdSec, DHCP and Unbound DNS, plus about a dozen Linux, Windows and Android agents. Encrypted the syslog transport with TLS (stunnel, internal PKI).
  • Detection engineering: wrote custom decoders and rules mapped to MITRE ATT&CK, added GeoIP enrichment and built a threat-geolocation dashboard. Fixed silent ingestion failures at the root cause (decoder anchoring, chrooted daemons, a syslog boot race after a pfSense upgrade).
  • Detection-as-code: put the ruleset under Git with a written change procedure and a non-regression suite that replays real logs (20/20 passing). Added a pipeline health watchdog that alerts on drops in volume, parsing or freshness.
  • SOAR (n8n): Wazuh webhooks feed AbuseIPDB enrichment, multi-rule correlation, deduplication, enriched Telegram alerts and a daily digest. Designed and validated automatic IP blocking on pfSense through Wazuh Active Response (least-privilege SSH account, pf table).
  • AI-assisted triage: each critical alert opens a ticket that an LLM agent triages through home-built read-only MCP servers (Wazuh, Proxmox). The agents are controlled from a Matrix/Element X SOC room. Agent privileges were hardened after an observed tool-bypass attempt.
  • DFIR: deployed Velociraptor on 9 endpoints and forwarded its audit log to Wazuh, with rules for remote execution and agent tampering.
  • Purple-team lab on an isolated network: Windows AD domain controller (Kerberos and DCSync auditing, Sysmon-modular, Atomic Red Team), DVWA and Metasploitable 3.
